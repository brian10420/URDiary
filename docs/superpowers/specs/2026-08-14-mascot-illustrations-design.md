## 1. 目標與風格錨點

以現有 App icon（`desktop/assets/icon.jpg` 的書本吉祥物）為唯一風格基準，建立一套**手寫 SVG** 的吉祥物視覺層：等待動畫、空狀態插圖、登入歡迎、操作彩蛋、月曆分類圖標。零外部相依（不引入 Lottie／圖片庫），全部 inline SVG＋CSS 動畫。

**基底造型（使用者選定「正面 Q 版」）**——共用參數：

- 描邊 `#4b2e1e`（粗描邊，48 viewBox 下約 3.2；200 viewBox 下約 9）
- 書皮 `#b98d6d`、書頁 `#f9f3e6`、書籤 `#5fd0a0`、眼嘴 `#2b1a10`、腮紅 `#f0a78f`（55% 不透明）
- 圓角厚實比例、豆豆眼＋微笑

## 2. 非目標

- 使用者上傳自訂分類圖、AI 描述生圖（未來 spec，屆時評估圖像生成 API）
- 全站配色／版面改版——只加視覺元素，不動既有佈局
- 吉祥物出現在「每一則」聊天訊息旁（干擾閱讀，不做）

## 3. 等待動畫（使用者選定「左右搖擺」）

- keyframes：`rotate(-5deg) ↔ rotate(5deg)`，1.8s ease-in-out infinite，`transform-origin: 50% 88%`
- 搭配「思考中…」三點 opacity 脈動（1.2s，錯開 0.2s）
- 使用位置：
  1. 聊天「陪伴者思考中」泡泡（吉祥物 26px＋文字）
  2. 頁面／視圖載入
  3. AI 生成日記等待
- **`prefers-reduced-motion: reduce` 時停用動畫**，改靜態圖＋文字

## 4. 姿態套件（7 款，全部經視覺確認通過）

| # | 姿勢 | 用途 | 關鍵元素 |
|---|------|------|----------|
| 1 | 打瞌睡 | 空日記列表 | 閉眼＋zzz＋斜靠鉛筆；文案「還沒有日記——跟我聊聊今天吧」 |
| 2 | 舉手看月曆 | 空行事曆 | 舉手＋空白月曆紙；「這週還空空的，要記點什麼嗎？」 |
| 3 | 歪頭問號 | 空卡片頁／搜尋無結果 | 歪 5°＋抿嘴＋大問號 |
| 4 | 揮手歡迎 | 登入／歡迎頁 | 瞇瞇笑眼＋腮紅＋舉手 |
| 5 | 開心跳 | 存日記成功彩蛋 | 跳起＋金星四散＋地面陰影；1.5s 後淡出、不擋操作 |
| 6 | 端茶問候 | 每日 check-in 問候旁 | 捧冒熱氣的白茶杯 |
| 7 | 睡帽晚安 | 夜間（22:00–05:00）存日記成功時取代「開心跳」的彩蛋版本 | 藍睡帽 `#7f96c9`＋奶油毛球＋月牙星空、深色底 |

### 彩蛋出現原則（會寫進實作的硬規則）

- 彩蛋**只綁明確操作事件**（存日記成功、check-in、夜間收尾），永不由對話內容觸發；聊天區域只有安靜的搖擺／靜態吉祥物
- **情緒門檻**：存日記彩蛋依該篇日記的情緒分析結果分流——負向情緒時不放「開心跳」，改用靜態安靜陪伴版；危機模式（crisis）相關流程中一律不出現任何彩蛋
- 晚安版＝夜間（22:00–05:00，與 5am 日記換日相容）存日記成功時的彩蛋替代版本，同樣受情緒門檻約束（負向情緒→靜態版）

**兩級渲染（使用者決策）**：

- 月格子：**18px 無臉版**（只留道具輪廓與顏色）取代現有 `cat-dot` 色點
- 事件列表／詳情：**24px 有臉版**
- 圖標顏色內嵌於 SVG；既有 `--cat-*` CSS 變數保留給殘留的文字／色點用途，並新增 `--cat-travel`（light/dark 兩組）

**新增 travel 分類的工程**：`backend/app/database/models.py` 註解與（若有）驗證集合、前端 `calendar_module.js` CATEGORIES、`i18n.js` 兩語（出遊／Outing）、`calendar.css` 色票（light/dark）、事件表單選項。舊資料不受影響（未知分類 fallback `other`，前端已有此邏輯）。

## 6. 資產與工程結構

- SVG 全部以**模板字串內嵌於 `desktop/js/mascot.js`**（單一來源，不建 assets 目錄、無額外 HTTP 請求、動畫 class 可直接作用於內部元素）；動畫 keyframes 集中 `desktop/css/mascot.css`
- `mascot.js` 對外只暴露注入函式：`mascotLoading()`、`mascotEmpty(kind)`、`mascotEgg(kind, {emotion})`、`categoryIcon(category, size)`，各模組（chat／diary／calendar／登入）只呼叫不重複拼 SVG
- **PWA**：`mascot.js` 與 `mascot.css` 需加入 `desktop/sw.js` app-shell precache 清單（否則離線缺圖）
- 空狀態文案進 `i18n.js` 兩語
- 深色模式：吉祥物本體色在深色底可讀（晚安版自帶深色場景）；描邊色不隨主題變

## 7. 測試與驗收

1. vitest：`mascot.js` 注入函式（kind 分流、emotion 門檻分支、未知分類 fallback、時段判斷 22:00–05:00）
2. sw precache 清單含 `mascot.js`／`mascot.css`（既有 sw 測試模式擴充）
3. 手動：`prefers-reduced-motion` 開啟時動畫停用；桌面＋手機 PWA 各走一輪（月格 18px 可讀性實看）；深淺色主題各檢一次
4. 既有 pytest／vitest 全綠（後端僅 travel 分類註解／驗證的小改動）
