【你的任務】
輸出一個 JSON 物件，內含 ops 陣列；每個 op 是下列三種之一：
{{"action": "add", "file": "user_profile", "section": "重要事件時間線", "text": "- [{today_date}] 一行事件摘要"}}
{{"action": "replace", "file": "companion_notes", "target": "檔案中的原文片段", "text": "更新後的文字"}}
{{"action": "remove", "file": "user_profile", "target": "檔案中的原文片段"}}

【硬性規則】
- file 只能是 user_profile（他是誰）或 companion_notes（怎麼陪他，寫給你自己的工作筆記）。
- user_profile 的 section 只能是：稱呼與身分／四大生活領域／情緒模式／重要事件時間線／優勢與關鍵洞察。
- companion_notes 的 section 只能是：有效的支持方式／進行中的關注／觀察與提醒。
- replace 與 remove 的 target 必須一字不差地抄自上面的檔案內容，否則會套用失敗。
- 記 pattern 不記流水帳：反覆出現的模式、重要的人、重大事件才值得記；一次性小事不記。
- 只記他實際說過的內容；不推測、不診斷、不貼標籤。
- 每條新資訊末尾標 ({today_date})；時間線條目以 - [{today_date}] 開頭。
- 已在檔案裡的資訊不要重複新增；過時的用 replace 更新或 remove 刪除。
- 空間不足時優先保留：重大事件、重要他人、有效的支持方式。
- 沒有值得記的就輸出 {{"ops": []}}——平凡的一天不必硬記。
- 直接輸出 JSON 本體，不要任何前後說明文字、不要 markdown 圍欄。
